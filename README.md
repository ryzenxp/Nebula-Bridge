# 🛰️ Nebula Bridge

[![Network: Ethereum](https://img.shields.io/badge/Network-Ethereum-00ff41.svg)](#)
[![Theme: Cyberpunk](https://img.shields.io/badge/UI-Cyberpunk-black.svg)](#)

Nebula Bridge is a decentralized **Token Vesting and Airdrop Portal**. It allows blockchain projects to distribute tokens to team members and investors via linear time-locks, ensuring long-term project stability and trust.

## 🛠️ Features

- **🛡️ Linear Vesting:** Tokens are released second-by-second based on smart contract logic.
- **📟 Terminal UI:** A high-contrast, cyberpunk-inspired dashboard for "power users."
- **📊 Real-Time Analytics:** Visual progress bars showing exactly how much of your allocation is unlocked.
- **⚡ Gas Optimized:** Uses efficient storage patterns to reduce claim fees.

## 📁 Project Structure

- `NebulaVesting.sol`: The core logic for locking and releasing ERC-20 tokens.
- `index.html`: The all-in-one "Matrix-style" frontend dashboard.

## 🚀 Deployment

1. Deploy the `NebulaVesting.sol` contract with your token address.
2. Grant the contract `transferFrom` permissions for the initial deposit.
3. Host the `index.html` on any IPFS provider (Fleek/Pinata).
